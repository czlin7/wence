# Wence

Wence helps securities professionals turn a client's stock question into a clear, evidence-led conversation.

## Get started

1. Download and unzip the project folder. Keep its contents together.
2. Start Wence:
   - **Windows:** double-click `scripts/start-windows.bat`.
   - **macOS:** run `chmod +x scripts/start-macos.command` once in Terminal. Then Control-click the launcher and choose **Open** the first time.
3. Save your Tushare token in `api_key.txt` beside this README for automatic startup, or paste it when prompted. Wence opens in your browser.
4. On first launch, Wence downloads and prepares the local conversation assistant (about 1.3 GB). The browser shows setup progress; later launches reuse it.
5. Enter a stock code or name, add the client's question, and select **Analyze**.

Keep the launcher window open while using Wence. Press **Ctrl+C** in the Windows launcher window, or close the macOS terminal window, to stop it.

## What you can do

- Compare a stock's move with the wider market and its industry.
- Review price trends, trading activity, valuation, and available financial indicators.
- Explore historical days with similar price and volume behavior.
- Prepare client-friendly explanations and check draft wording.

Wence uses the Tushare data available to your account. If a data item is unavailable, the app shows that it could not be retrieved. Check announcements and event-driven questions with an authorized or official source.

## Supported computers

Wence runs on 64-bit Windows and on Intel or Apple Silicon Macs. An internet connection and a Tushare token are required for stock analysis.
