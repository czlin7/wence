# 问策台 Wence

问策台帮助证券从业人员把客户的股票问题整理成清楚、有数据依据的沟通内容。

## 快速开始

1. 下载并解压项目文件夹，保持文件夹内容完整。
2. 启动问策台：
   - **Windows：** 双击 `scripts/start-windows.bat`。
   - **macOS：** 在终端运行一次 `chmod +x scripts/start-macos.command`。首次启动时，再按住 Control 键点击启动器并选择**打开**。
3. 将 Tushare Token 保存到本 README 同目录的 `api_key.txt`，即可自动读取；也可以在启动提示中直接粘贴。问策台会在浏览器中打开。
4. 首次启动时，问策台会自动下载并配置本地话术助手（约 1.3 GB）；页面会显示进度，之后无需再次下载。
5. 输入股票代码或名称，填写客户问题，然后选择**分析股票**。

使用期间请保持启动窗口打开。停止程序时，在 Windows 启动窗口按 **Ctrl+C**，或关闭 macOS 终端窗口。

## 可以做什么

- 对比个股表现与整体市场、所属行业的表现。
- 查看价格趋势、交易活跃度、估值和可获取的财务指标。
- 查看历史上价格和成交量特征相似的交易日。
- 整理客户沟通话术，并检查拟回复内容。

问策台使用 Tushare 账户当前可访问的数据。若某项数据无法获取，界面会显示缺失状态。公告及事件类问题请通过授权或官方渠道核实。

## 支持的电脑

支持 64 位 Windows，以及 Intel 或 Apple Silicon Mac。股票分析需要联网并提供 Tushare Token。
